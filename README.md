# Simple Calculator

Aplikasi calculator sederhana berbasis web yang memiliki fitur:

- Operasi dasar: tambah, kurang, kali, bagi
- Tombol clear dan delete
- Input angka dan desimal
- Keyboard support
- Tampilan responsif

## Cara menjalankan

Buka file `index.html` di browser Anda, atau jalankan server lokal sederhana seperti:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000` di browser.

## Struktur file

- `index.html` — layout aplikasi
- `style.css` — styling tampilan
- `script.js` — logika kalkulator

## Preview

Aplikasi ini siap digunakan untuk kebutuhan kalkulasi harian dengan tampilan yang bersih dan sederhana.
